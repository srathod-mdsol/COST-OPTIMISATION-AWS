Security Considerations

IAM Permissions and Best Practices

Required IAM Permissions

{ "Version": "2012-10-17", "Statement": [{ "Effect": "Allow", "Action": [ "ec2:Describe*", "rds:Describe*", "rds:ListTagsForResource", "cloudwatch:GetMetricStatistics", "pricing:GetProducts" ], "Resource": "*" }] }

Best Practices

  • Use IAM roles instead of access keys when possible
  • Rotate credentials regularly
  • Least privilege - grant only required permissions
  • Use VPC endpoints for AWS API access
  • Secure database files with chmod 600
  • Enable encryption at rest
  • Enable CloudTrail for audit logging

Prerequisites and Limitations

Prerequisites

  • Python 3.9 or higher
  • AWS Account with billing access
  • IAM User/Role with read-only permissions
  • Database (SQLite default, PostgreSQL recommended)
  • Internet access to AWS APIs

Limitations

  • No auto-termination: Tool recommends, does NOT delete
  • Cost data delay: Slight delay in pricing data
  • Region scope: Must run per-region or specify all
  • API rate limits: Subject to AWS throttling
  • Historical data: Limited to 90 days (CloudWatch)

Troubleshooting

Common Issues and Solutions

Database Connection

Error: "Unable to connect to database"

# Verify DATABASE_URL echo $DATABASE_URL

AWS API Throttling

Error: "Rate exceeded"

  • Adjust MAX_CONCURRENT_WORKERS
  • Implement exponential backoff
  • Request limit increase from AWS

Missing Pricing Data

Error: "No pricing found"

# Run pricing loader python -m etl.pricing_loader

ETL Lock Errors

Error: "ETL process is locked"

# Force unlock python -c "from etl.orchestrator import ETLOrchestrator; e = ETLOrchestrator(); e.force_unlock()"

Architecture Decisions

Key Design Principles

⚡

Dual-Mode Operation

ETL mode for dashboard (cached data), Direct API mode for CLI (real-time). Automatic detection based on execution context.

🗄️

Database Agnostic

SQLAlchemy for abstraction. Support for 5 database backends. Automatic schema creation.

🏗️

Separation of Concerns

ETL layer for data collection, Analysis layer for processing, UI layer for presentation.

🔌

Pluggable Services

Base manager class with service-specific implementations. Easy to extend for new AWS services.
